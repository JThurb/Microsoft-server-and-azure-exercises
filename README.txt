In this course, the lab was created using VMware workstation pro. 
I learned to: 
- plan and implement basic Windows Server
- joining Windows 10 workstation and Linux Ubuntu server to domain
- to use Active Directory for managing organization. Creating Users, Group Policys, Organizational Units and applying some security enhancements. 
- use Windows Azure. I connected my local Windows 2022 server to Azure ARC, used EntraID to make new users and implemented virtual machine through Azure.

There is picture of the lab topology, report about security enhancements and report about using Azure for managing users and virtual machines.
